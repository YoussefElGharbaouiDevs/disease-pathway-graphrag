# Ressources

Scientific sources for the disease pathway knowledge graph.

- 14 original, open-licensed full-text PDFs are included in this public repository.
- One additional paper is recorded as a source link because its PDF is restricted to personal use. A downloaded local copy may exist but is Git-ignored.
- Two further shortlisted papers remain pending full-text access.
- `sources.json` records stable IDs, DOI/PMID identifiers, file paths, checksums and availability.
- `ATTRIBUTION.md` provides authorship, original publication links and individual license notices.
- `supplements/` contains the two original Jensen workbooks: 4,014 diagnosis pairs and 1,171 four-diagnosis trajectories. Their publisher filenames end in `.zip`, but their contents use the Excel workbook format. Open a separate copy with an `.xlsx` extension when needed.

These are research sources, not an already validated graph. Preserve source context and verify evidence before accepting relationships into the knowledge base.
